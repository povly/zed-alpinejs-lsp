# Alpine.js LSP

[English](README.md) | [Русский](README.ru.md)

Языковой сервер для [Alpine.js](https://alpinejs.dev/) в редакторе [Zed](https://zed.dev) — документация при наведении, переход к определению и автодополнение для директив Alpine в HTML и Blade файлах.

## Возможности

### Документация при наведении

Наведите курсор на любую директиву Alpine или магическое свойство, чтобы увидеть документацию:

| Директива | Описание |
|---|---|
| `x-data` | Объявляет новую область компонента Alpine |
| `x-show` | Переключает `display:none` в зависимости от истинности выражения |
| `@click` / `x-on:click` | Назначает обработчик события |
| `$el`, `$refs`, `$store`, `$dispatch` | Сигнатуры и описания магических свойств |

### Переход к определению

Перейдите от ссылки на компонент к его определению — даже в другом файле:

- `x-data="mainMap"` → переход к `Alpine.data('mainMap', ...)` в `index.js`
- `@click="selectTab()"` → переход к методу внутри `Alpine.data('tabs', ...)`
- `x-data="{ open: false }"` → переход к свойству внутри инлайн `x-data`

### Автодополнение

- **Магические свойства** — введите `$` внутри любого атрибута Alpine, чтобы получить `$el`, `$refs`, `$store`, `$dispatch` и др.
- **Члены области видимости** — введите `.` чтобы увидеть методы и свойства из текущей области `x-data`
- **Межфайловые члены** — компоненты, зарегистрированные через `Alpine.data()` и `Alpine.store()` в других файлах, появляются в автодополнении

### Индексатор рабочего пространства

При запуске сервер сканирует всё рабочее пространство на наличие:

- `Alpine.data('name', () => ({ ... }))` — регистрации компонентов
- `Alpine.store('name', { ... })` — регистрации глобальных хранилищ
- Инлайн `x-data="{ ... }"` — объявления внутри файлов

Все символы индексируются и доступны для наведения, перехода и автодополнения — во всех HTML и Blade файлах.

## Установка

### Из маркетплейса Zed (на рассмотрении)

Найдите "alpine" в `zed: extensions` и установите.

### Вручную / Dev Extension

```bash
git clone https://github.com/povly/zed-alpinejs-lsp.git
cd zed-alpinejs-lsp
```

В Zed откройте `zed: install dev extension` и укажите путь к склонированной директории.

> Требуется Node.js 18+, установленный в системе.

## Поддерживаемые языки

- **Blade** (`.blade.php`)
- **HTML** (`.html`, `.htm`)

## Как это работает

Расширение поставляет языковой сервер на Node.js, упакованный в Rust/WASM обёртку расширения Zed.

```
extension.wasm (Rust)
  ├── Встраивает server/dist/*.js через include_str!()
  ├── При установке: распаковывает JS файлы + запускает npm install
  └── Запускает: node server/dist/index.js --stdio

Node.js LSP сервер
  ├── index.js     — точка входа, LSP протокол
  ├── server.js    — обработчики hover, definition, completion
  ├── workspace.js — сканер рабочего пространства и индекс символов
  ├── extractor.js — парсер атрибутов Alpine
  ├── xdata.js     — парсер членов инлайн x-data
  └── data.js      — база магических свойств и директив
```
